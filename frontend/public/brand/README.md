# Equans Switzerland logo

`equans-switzerland.svg` is the complete, unmodified official vector from the Equans Switzerland website:
https://www.equans.ch/_nuxt/logo_equans_pos.BxvS6rP2.svg

The logo retains its original orientation, colours, gradients, lettering and proportions. It is displayed as an image, separately from the BidGenius AI product name and slogan. On compact layouts, the full logo moves to the top bar; the navigation uses a BG product monogram.

Brand reference: https://www.equans.com/equans-brand-centre

The official logo's colour literals are intentional and should not be replaced with application theme tokens.
